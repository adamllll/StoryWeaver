# 测试脚本使用指南

## 测试数据生成脚本 (seed_test_data.py)

### 功能说明
自动生成测试用户、小说、章节、角色和世界观数据，用于快速搭建测试环境。

### 使用方法

#### 1. 基础用法（首次生成）
```bash
cd backend
python scripts/seed_test_data.py
```

**效果**：
- 创建测试用户 `test_user`（如果不存在）
- 生成 2 个测试小说：
  - 【测试】仙侠奇缘录（玄幻类，含3章+3角色+2世界观）
  - 【测试】末世求生日记（科幻类，互动式，含2章+2角色+1世界观）

#### 2. 清空重建（重置测试数据）
```bash
python scripts/seed_test_data.py --clean
```

**效果**：
- 删除所有标题包含【测试】的小说
- 删除测试用户 `test_user`（会级联删除其所有小说）
- 重新生成全部测试数据

### 测试场景覆盖

#### ✅ 可测试功能
1. **AI续写**：第三章未完成，内容超过10字，可直接测试续写
2. **AI扩写**：所有章节内容充足（>500字），选中5字以上即可扩写
3. **AI重写**：同上，选中任意文本测试重写
4. **大纲显示**：两个小说都有大纲字段，会显示在工作区左侧
5. **章节管理**：多章节小说，可测试排序、删除、新增
6. **角色管理**：每个小说都有2-3个角色，可编辑
7. **互动分支**：第二个小说支持互动，可测试分支生成

#### ⚠️ 注意事项
- 所有测试数据标题都带【测试】前缀，方便识别
- 脚本具备幂等性，重复执行不会产生重复数据（除非使用 `--clean`）
- 章节内容长度符合业务规则（续写≥10字，扩写/重写≥5字）
- 使用事务保证数据完整性，出错会自动回滚

### 开发建议

#### 日常开发流程
```bash
# 1. 首次运行生成测试数据
python scripts/seed_test_data.py

# 2. 登录测试账号
# 用户名: test_user
# 密码: test123

# 3. 在工作区测试AI功能
# - 打开【测试】仙侠奇缘录
# - 选择第三章（未完成）测试续写
# - 选中任意段落测试扩写/重写

# 4. 测试后重置环境
python scripts/seed_test_data.py --clean
```

#### 自定义测试数据
编辑 `seed_test_data.py` 中的 `TEST_NOVELS` 列表：
```python
TEST_NOVELS = [
    {
        "title": "【测试】你的小说标题",
        "description": "小说简介",
        "category": "玄幻",  # 可选：玄幻、科幻、言情、悬疑等
        "outline": "第一章：...\n第二章：...",
        "chapters": [
            {
                "title": "第一章",
                "order_num": 1,
                "content": "章节内容（建议>500字）",
            }
        ],
        # ... 更多字段
    }
]
```

### 故障排查

#### 问题1：导入模块错误
```
ModuleNotFoundError: No module named 'app'
```
**解决**：确保在 `backend/` 目录下执行脚本

#### 问题2：数据库文件不存在
```
sqlalchemy.exc.OperationalError: unable to open database file
```
**解决**：检查 `backend/.env` 中的 `DATABASE_URL` 配置

#### 问题3：密码哈希失败
```
ValueError: password hash could not be identified
```
**解决**：确保已安装 `passlib` 和 `argon2-cffi`：
```bash
pip install passlib argon2-cffi
```
