## 测试特点

1. **独立性**：每个测试独立运行，使用内存数据库
2. **快速**：使用Mock AI服务，无需真实API调用
3. **完整性**：覆盖正常流程、边界条件、错误处理
4. **可维护性**：使用fixtures复用测试数据
5. **清晰性**：测试命名描述性强，易于理解

## 技术亮点

1. **StaticPool连接池**：确保内存数据库在所有连接间共享
2. **事务回滚**：每个测试后自动回滚，保持数据库干净
3. **Mock AI服务**：避免外部依赖，测试稳定快速
4. **测试标记**：支持按类型运行测试（unit/integration）
5. **简洁设计**：遵循KISS原则，代码简洁高效

## 使用方法

```bash
# 进入backend目录
cd story-weaver/backend

# 运行所有测试
pytest

# 运行特定模块
pytest tests/test_auth.py

# 运行单元测试
pytest -m unit

# 查看详细输出
pytest -v

# 生成覆盖率报告（需安装pytest-cov）
pip install pytest-cov
pytest --cov=app --cov-report=html
```
