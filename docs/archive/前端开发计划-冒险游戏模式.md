## 整体架构设计

### 设计原则

1. **组件化开发**：将 UI 拆分为可复用的小组件
2. **类型安全**：所有数据结构使用 TypeScript 定义
3. **响应式设计**：支持桌面端和移动端
4. **性能优化**：懒加载、代码分割、状态缓存
5. **用户体验优先**：流畅的动画、即时反馈、错误处理

### 技术选型说明

| 技术 | 用途 | 理由 |
|------|------|------|
| **Next.js 14** | React 框架 | App Router 支持、SSR、代码分割 |
| **TypeScript** | 类型系统 | 类型安全、智能提示、减少 bug |
| **Tailwind CSS** | 样式方案 | 快速开发、一致性、响应式 |
| **shadcn/ui** | 组件库 | 可定制、无依赖、高质量 |
| **Zustand** | 状态管理 | 轻量级、简单、TypeScript 友好 |
| **Framer Motion** | 动画库 | 声明式动画、性能好、易用 |
| **React Query** | 数据获取 | 缓存、重试、自动刷新 |

**动画效果**：
- 数值变化：AnimatedNumber 组件（数字滚动）

- 新增物品：从上方飞入
- 新增事件：淡入 + 高亮 3 秒

**实现要点**：
```tsx
// 数值动画
function AnimatedNumber({ value, duration = 1000 }: Props) {
  const [displayValue, setDisplayValue] = useState(value);

  useEffect(() => {
    const start = displayValue;
    const end = value;
    const startTime = Date.now();

    const animate = () => {
      const now = Date.now();
      const progress = Math.min((now - startTime) / duration, 1);
      const current = Math.round(start + (end - start) * progress);

      setDisplayValue(current);

      if (progress < 1) {
        requestAnimationFrame(animate);
      }
    };

    animate();
  }, [value]);

  return <span>{displayValue}</span>;
}

// 状态条
function StatBar({ label, value, max, color }: Props) {
  const percentage = (value / max) * 100;

  return (
    <div className="stat-bar">
      <div className="stat-label">{label}</div>
      <div className="stat-value">
        <AnimatedNumber value={value} /> / {max}
      </div>
      <div className="stat-bar-bg">
        <motion.div
          className={`stat-bar-fill bg-${color}-500`}
          initial={{ width: 0 }}
          animate={{ width: `${percentage}%` }}
          transition={{ duration: 0.8, ease: "easeOut" }}
        />
      </div>
    </div>
  );
}
```

```tsx
function ChoiceCard({ choice, onSelect, disabled, playerState }: Props) {
  const canSelect = checkRequirements(choice.state_requirements, playerState);

  return (
    <motion.div
      className={cn(
        "choice-card",
        !canSelect && "disabled",
        getDifficultyClass(choice.difficulty)
      )}
      whileHover={canSelect ? { y: -4, scale: 1.02 } : {}}
      whileTap={canSelect ? { scale: 0.98 } : {}}
      onClick={() => canSelect && onSelect(choice)}
    >
      {/* 内容 */}
    </motion.div>
  );
}

// 前置条件检查
function checkRequirements(
  requirements: Record<string, string> | null,
  state: PlayerState
): boolean {
  if (!requirements) return true;

  for (const [key, condition] of Object.entries(requirements)) {
    if (!(key in state)) return false;

    const value = state[key];

    if (condition.includes(">=")) {
      const threshold = parseInt(condition.split(">=")[1].trim());
      if (value < threshold) return false;
    }
    // ... 其他条件
  }

  return true;
}
```

#### 3. DiceRollAnimation（判定动画）⭐⭐

**功能**：显示骰子滚动动画和判定结果

**Props**：
```typescript
interface DiceRollAnimationProps {
  rollValue: number;     // 最终投骰值
  target: number;        // 目标值
  success: boolean;      // 是否成功
  onComplete: () => void; // 动画完成回调
}
```

**动画流程**：
```
1. 淡入（0.2s）
   ↓
2. 骰子滚动（1.0s）
   - 数字快速变化（1-100）
   - 骰子图标旋转
   ↓
3. 停止在最终值（0.3s）
   - 数字固定
   - 震动效果
   ↓
4. 显示目标值（0.5s）
   - 目标值淡入
   ↓
5. 显示结果（0.5s）
   - 成功/失败文本
   - 背景颜色变化
   ↓
6. 保持 1 秒后淡出（0.5s）
   ↓
7. 触发 onComplete 回调
```

**组件结构**：
```tsx
<DiceRollAnimation>
  <Overlay />

  <AnimationContainer>
    <DiceIcon rotating={isRolling} />

    <RollValue>
      {isRolling ? randomValue : rollValue}
    </RollValue>

    <AnimatePresence>
      {showTarget && (
        <TargetValue>
          目标：{target}
        </TargetValue>
      )}
    </AnimatePresence>

    <AnimatePresence>
      {showResult && (
        <ResultBanner success={success}>
          <Icon>{success ? "✅" : "❌"}</Icon>
          <Text>{success ? "成功！" : "失败..."}</Text>
          {isCritical && (
            <CriticalText>
              {rollValue <= 5 ? "大成功！🎉" : "大失败！💀"}
            </CriticalText>
          )}
        </ResultBanner>
      )}
    </AnimatePresence>
  </AnimationContainer>
</DiceRollAnimation>
```

**实现要点**：

### Zustand Store 设计

```typescript
// lib/adventure-store.ts

import { create } from 'zustand';
import { devtools, persist } from 'zustand/middleware';

interface AdventureState {
  // 当前冒险数据
  currentAdventure: Adventure | null;
  currentNode: StoryNode | null;

  // UI 状态
  isLoading: boolean;
  isRolling: boolean;
  rollResult: RollResult | null;

  // Actions
  setAdventure: (adventure: Adventure) => void;
  setCurrentNode: (node: StoryNode) => void;
  makeChoice: (choice: Choice) => Promise<void>;
  loadAdventure: (id: number) => Promise<void>;
  reset: () => void;
}

export const useAdventureStore = create<AdventureState>()(
  devtools(
    persist(
      (set, get) => ({
        // 初始状态
        currentAdventure: null,
        currentNode: null,
        isLoading: false,
        isRolling: false,
        rollResult: null,

        // Actions
        setAdventure: (adventure) => set({ currentAdventure: adventure }),

        setCurrentNode: (node) => set({ currentNode: node }),

        makeChoice: async (choice) => {
          const { currentAdventure } = get();
          if (!currentAdventure) return;

          set({ isRolling: true });

          try {
            const result = await apiClient.post(
              `/api/adventures/${currentAdventure.id}/choose`,
              {
                choice_index: choice.index,
                choice_text: choice.text,
              }
            );

            set({
              rollResult: result,
              isRolling: false,
            });

            // 等待动画完成后更新状态
            setTimeout(() => {
              set({
                currentNode: result.new_node,
                currentAdventure: {
                  ...currentAdventure,
                  player_state: result.state_after,
                },
                rollResult: null,
              });
            }, 3500);
          } catch (error) {
            set({ isRolling: false });
            throw error;
          }
        },

        loadAdventure: async (id) => {
          set({ isLoading: true });

          try {
            const adventure = await apiClient.get(`/api/adventures/${id}`);
            const nodes = await apiClient.get(`/api/adventures/${id}/nodes`);

            set({
              currentAdventure: adventure,
              currentNode: nodes[nodes.length - 1], // 最新节点
              isLoading: false,
            });
          } catch (error) {
            set({ isLoading: false });
            throw error;
          }
        },

        reset: () => set({
          currentAdventure: null,
          currentNode: null,
          rollResult: null,
        }),
      }),
      {
        name: 'adventure-storage',
        partialize: (state) => ({
          currentAdventure: state.currentAdventure,
        }),
      }
    )
  )
);
```

```typescript
import axios from 'axios';

const apiClient = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL || 'http://localhost:8000',

// 请求拦截器：添加认证 Token
apiClient.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器：统一错误处理
apiClient.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      // Token 过期，跳转登录
      window.location.href = '/login';
    }

    const message = error.response?.data?.detail || '请求失败';

    throw error;
  }
);
```

```tsx
function TypewriterText({ text }: { text: string }) {
  const [displayText, setDisplayText] = useState("");

  useEffect(() => {
    let i = 0;
    const interval = setInterval(() => {
      if (i < text.length) {
        setDisplayText(text.slice(0, i + 1));
        i++;
      } else {
        clearInterval(interval);

    }, 30); // 30ms 每个字
```
