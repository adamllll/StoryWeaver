### 问题 2：字段名称差异

#### 2.1 Pydantic V1 vs V2 警告

**警告内容**：
```
PydanticDeprecatedSince20: `min_items` is deprecated, use `min_length` instead
PydanticDeprecatedSince20: `max_items` is deprecated, use `max_length` instead
```

**建议**：
- 💡 将后端 Pydantic Schema 中的 `min_items`/`max_items` 改为 `min_length`/`max_length`
- 💡 将 `@validator` 改为 `@field_validator`（Pydantic V2 语法）
- ⚠️ 影响：仅是警告，不影响功能，但应尽快迁移

#### 2.2 datetime.utcnow() 过时警告

**警告内容**：
```
DeprecationWarning: datetime.datetime.utcnow() is deprecated
Use timezone-aware objects: datetime.datetime.now(datetime.UTC)
```

**建议**：
- 💡 将 `datetime.utcnow()` 改为 `datetime.now(datetime.UTC)`
- 💡 影响文件：
  - `app/utils/auth.py:31, 35`
  - `app/routers/adventures.py:564`
  - `app/routers/conversations.py:133`
