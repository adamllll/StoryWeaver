# 一键部署脚本使用指南

> **10 分钟完成部署！只需一条命令！** (￣▽￣)ノ

## 🚀 快速开始

### 在服务器上执行一条命令

```bash
# 下载并运行部署脚本
curl -fsSL https://raw.githubusercontent.com/adamllll/StoryWeaver/main/deploy-1panel.sh | sudo bash
```

**或者**

```bash
# 克隆项目后执行
git clone https://github.com/adamllll/StoryWeaver.git
cd StoryWeaver
sudo bash deploy-1panel.sh
```

---

## 📋 部署流程

脚本会自动完成以下步骤：

### 1. 环境检查 ✅
- 检查是否为 root 用户
- 检查必要命令（docker、git、openssl）
- 验证 1Panel 环境

### 2. 选择部署路径
- **选项 1**（推荐）：`/opt/1panel/apps/storyweaver`
- **选项 2**：自定义路径

### 3. 克隆项目代码
- 自动从 GitHub 克隆最新代码

### 4. 配置环境变量
脚本会询问：
- **域名或 IP**：例如 `storyweaver.example.com`
- **是否使用 HTTPS**：推荐选择 `y`
- **OpenAI API Key**：你的 API 密钥
- **API Base URL**：可选，默认 OpenAI 官方

脚本会自动：
- 生成安全的 JWT 密钥
- 创建 `backend/.env` 配置
- 创建 `frontend/.env.local` 配置
- 创建数据目录

### 5. 启动容器 🐳
- 自动构建 Docker 镜像（首次需要 3-5 分钟）
- 启动后端和前端容器
- 等待容器就绪

### 6. 显示配置说明 📝
- OpenResty 反向代理配置
- 访问地址
- 管理命令

## 🎯 部署后操作（必须完成！）

### 配置 OpenResty 反向代理

部署脚本会显示详细的配置说明，你需要在 **1Panel** 中完成：

#### 步骤 1: 创建网站
1. **1Panel** → **网站** → **创建网站**
2. **网站类型**：反向代理
3. **域名**：你在脚本中输入的域名
4. **代理地址**：`http://127.0.0.1:3000`
5. **SSL**：选择 Let's Encrypt 自动申请（如果用 HTTPS）

#### 步骤 2: 添加 API 路由
1. **网站列表** → 你的网站 → **配置**
2. 在 `location /` 块**前面**添加：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;

    proxy_connect_timeout 120s;
    proxy_send_timeout 120s;
    proxy_read_timeout 120s;
}
```

3. **保存** → **重载配置**

#### 步骤 3: 访问应用
- 打开浏览器访问你的域名
- 看到登录页面说明部署成功！✅

## 📊 部署信息查看

### 查看容器状态
```bash
cd /opt/1panel/apps/storyweaver
docker compose ps
```

### 查看日志
```bash
# 实时查看所有日志
docker compose logs -f

# 只看后端日志
docker compose logs -f backend

# 只看前端日志
docker compose logs -f frontend
```

### 检查健康状态
```bash
# 后端健康检查

# 预期返回

```


## ❓ 常见问题

### Q1: 脚本执行失败，提示 "Permission denied"
**A**: 必须使用 root 用户或 sudo：
```bash
sudo bash deploy-1panel.sh
```

### Q2: 克隆项目失败
**A**: 检查服务器网络连接，或手动克隆后执行：
```bash
git clone https://github.com/adamllll/StoryWeaver.git
cd StoryWeaver
sudo bash deploy-1panel.sh
```

### Q3: 容器启动失败
**A**: 查看详细日志：
```bash
docker compose logs
```

常见原因：
- 端口被占用（8000 或 3000）
- 内存不足（需要至少 2GB）

### Q4: 访问域名显示 502
**A**:
1. 确认容器正在运行：`docker compose ps`
2. 确认 OpenResty 配置正确
3. 确认域名 DNS 解析正确

### Q5: 如何更改配置？
**A**: 编辑配置文件后重启：
```bash
# 编辑后端配置
nano /opt/1panel/apps/storyweaver/backend/.env

# 编辑前端配置
nano /opt/1panel/apps/storyweaver/frontend/.env.local

# 重启容器
docker compose restart
```

## 🔧 进阶配置

### 启用 Swap（2GB 服务器必备）

1. **1Panel** → **主机** → **系统调优** → **Swap**
2. 配置：
   - 启用 Swap
   - 大小：2048 MB
   - Swappiness：10

### 配置自动备份

在服务器上创建定时任务：
```bash
# 每天凌晨 3 点备份
crontab -e

# 添加
0 3 * * * cp /opt/1panel/apps/storyweaver/backend/data/story.db /opt/1panel/apps/storyweaver/backend/data/backup-$(date +\%Y\%m\%d).db
```

### 清理旧镜像
```bash
# 清理未使用的镜像
docker image prune -a

# 清理所有未使用的资源
docker system prune -a
```
